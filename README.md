Healthcare Information Security Risk Assessment

1. Project Overview

This project presents a practical Information Security Risk Assessment for a fictional healthcare organisation, Hopewell Medical Centre.

The assessment demonstrates how cybersecurity risks can be identified, analysed, evaluated and treated to strengthen an organisation's information security posture.

The project applies recognised information security risk management principles and industry frameworks.

2. Project Objectives

- Identify and classify critical information assets.
- Identify potential threats and vulnerabilities.
- Evaluate information security risks based on likelihood and impact.
- Establish risk priorities.
- Recommend appropriate risk treatment measures.
- Improve information security governance and accountability.

3. Assessment Scope

The assessment focuses on the following areas:

- Patient information and electronic health records.
- User accounts and access privileges.
- Computer systems and network infrastructure.
- Data storage and backup systems.
- Employee security awareness.
- Third-party service providers.

4. Methodology and Frameworks

The project draws on the following recognised frameworks and standards:

- ISO/IEC 27001:2022 – Information Security Management Systems.
- ISO/IEC 27005 – Information Security Risk Management.
- NIST Cybersecurity Framework 2.0.

The assessment will follow these stages:

1. Context establishment.
2. Asset identification.
3. Risk identification.
4. Risk analysis.
5. Risk evaluation.
6. Risk treatment.
7. Monitoring and review.

5. Project Deliverables

Deliverable| Description
Asset Inventory| Identification of critical information assets
Risk Register| Documented information security risks
Risk Analysis| Assessment of likelihood and impact
Risk Evaluation| Risk prioritisation
Risk Treatment Plan| Recommended mitigation measures
Executive Summary| Management-level assessment findings

6. Disclaimer

Hopewell Medical Centre is a fictional organisation created solely for educational and professional portfolio purposes.

This project is a practical demonstration of cybersecurity GRC competencies and does not represent an actual organisational audit or certification assessment.
