
# Healthcare Information Security Risk Assessment
### An Illustrative Cybersecurity Governance, Risk and Compliance (GRC) Project

**Prepared by:** Oluebube Charity Nwaejike  
**Professional Role:** Cybersecurity GRC Professional  
**Project Category:** Information Security Risk Management  
**Organisation:** Hopewell Medical Centre (Fictional)

---

## 1. Project Overview

This project demonstrates a structured approach to identifying, analysing, evaluating, and treating information security risks within a fictional healthcare organisation, Hopewell Medical Centre.

Healthcare organisations process sensitive patient information and rely on information systems to support critical clinical and administrative operations. Protecting the confidentiality, integrity, and availability of these information assets is essential.

This assessment applies practical GRC principles to identify potential security weaknesses, evaluate associated risks, and recommend appropriate risk treatment measures.

## 2. Project Objectives

The objectives of this project are to:

- Identify and classify critical information assets.
- Identify potential threats and vulnerabilities.
- Assess information security risks using a consistent methodology.
- Evaluate inherent and target residual risk.
- Recommend appropriate risk treatment strategies.
- Establish accountability and remediation timelines.
- Communicate assessment findings and recommendations to management.

## 3. Assessment Scope

The assessment covers the following information assets:

- Electronic Health Records.
- Patient Registration Database.
- Staff Login Credentials.
- Hospital Computer Systems.
- Hospital Network Infrastructure.
- Laboratory Information Records.
- Data Backup Storage.
- Staff Personnel Records.
- Security Policies and Procedures.
- Third-Party Service Provider Records.

## 4. Methodology and Framework References

The assessment uses a qualitative 5×5 risk assessment matrix based on likelihood and impact.

**Risk Score = Likelihood × Impact**

Risk ratings are classified as:

| Score | Rating |
|---|---|
| 1–4 | Low |
| 5–9 | Moderate |
| 10–16 | High |
| 17–25 | Critical |

The assessment is informed by relevant principles from:

- ISO/IEC 27001:2022.
- ISO/IEC 27005.
- NIST Cybersecurity Framework 2.0.

The scoring thresholds are illustrative, project-specific criteria and are not universal requirements prescribed by these frameworks.

## 6. Key Assessment Findings

A total of 10 information security risks were identified and evaluated.

| Risk Rating | Number of Risks |
|---|---:|
| Critical | 2 |
| High | 7 |
| Moderate | 1 |
| Low | 0 |
| **Total** | **10** |

The two Critical risks relate to:

1. Unauthorised disclosure of patient records.
2. Compromise of staff login credentials.

The findings highlight the importance of strengthening access controls, authentication mechanisms, system security, backup arrangements, staff awareness, and third-party risk management.

## 7. Recommended Security Improvements

The assessment recommends:

- Implementing Multi-Factor Authentication.
- Strengthening role-based access control.
- Applying least-privilege principles.
- Establishing patch and vulnerability management processes.
- Improving network segmentation and monitoring.
- Maintaining protected backups and testing restoration.
- Conducting regular security awareness training.
- Strengthening third-party security assessments.
- Improving security policy governance and access restrictions.
